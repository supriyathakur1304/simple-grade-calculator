# Simple Grade Calculator

## Short Description

A simple C program that takes marks as input from the user and displays the corresponding grade.

## About the Project

The Simple Grade Calculator is a beginner-level C project. It accepts marks from 0 to 100 and checks the marks using `if, else-if` conditions.

The program displays whether the student has passed or failed and shows the appropriate grade.

## Features

* Takes marks from the user
* Checks whether marks are valid
* Displays the grade
* Displays pass or fail result
* Simple and easy to understand

## Installation

1. Install Visual Studio Code.
2. Install a C compiler.
3. Open Visual Studio Code.
4. Create a new folder for the project.
5. Create a C file, for example `marks.c`.
6. Copy the C program into the file.

## How to Run

### Step 1: Compile the Program

Open the VS Code terminal and run:

```bash
gcc marks.c -o marks
```

### Step 2: Run the Program

On Mac/Linux:

```bash
./marks
```

On Windows:

```bash
marks.exe
```

### Example Output

Enter the marks: 85
You are pass with grade B+
